## Testing & Quality Approach

I treat testing not as a separate phase of development but as part of the software itself:

**Development → Testing → Reporting → Automation**

- Test scenarios, positive/negative testing, and response validation
- UI and API test automation; Page Object Model and Pytest fixtures
- Django application testing
- Test reporting and defect tracking
- Automated test runs with CI/CD

For me, it is not enough for code to simply work; it should be readable, maintainable, reusable, and testable.
